# Hasta el Rabo Todo es Toro — web gratuita

Esta carpeta contiene una web estática lista para publicar sin pagar alojamiento.

## Archivos
- `index.html` — contenido y estructura de la página.
- `styles.css` — diseño y versión móvil.
- `script.js` — botón de compartir y año automático.
- `favicon.svg` — icono de la pestaña.

## Publicación gratuita: GitHub Pages
1. Crea una cuenta gratuita en GitHub.
2. Crea un repositorio nuevo. Para una dirección del tipo `TUUSUARIO.github.io`, llama al repositorio `TUUSUARIO.github.io`.
3. Sube estos cuatro archivos a la raíz del repositorio.
4. En Settings → Pages, selecciona la publicación desde la rama principal (`main`) y la carpeta `/root`.
5. GitHub te dará una dirección gratuita tipo `https://TUUSUARIO.github.io/`.

## Publicación gratuita: Cloudflare Pages
También puedes subir esta carpeta como proyecto de Pages. No necesita servidor ni base de datos.

## Importante
La página ya enlaza al podcast actual:
https://anchor.fm/hastaelrabo

Si después tienes enlaces de Spotify, Apple Podcasts, YouTube o redes sociales, cambia los enlaces correspondientes en `index.html`.

## Dominio propio
Un dominio como `hastaelrabo.com` normalmente tiene coste anual. Esta versión utiliza una dirección gratuita del proveedor (por ejemplo, `TUUSUARIO.github.io`), por lo que no tienes que pagar un dominio para empezar.
